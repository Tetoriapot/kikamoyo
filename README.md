# KIKAMOYO

ブラウザ上で幾何学模様を作成し、PNG・SVG・CSS・JSON・WebMへ書き出せるパターンジェネレーターです。

公開サイト: <https://tetoriapot.github.io/kikamoyo/>

## 開発

```bash
pnpm install
pnpm dev
```

テストは `pnpm test`、本番ビルドは `pnpm build` で実行できます。

## GitHub Pages版について

GitHub Pages版では、プロジェクトと表示設定をブラウザ内に保存します。別端末への移行やバックアップにはプロジェクト管理画面のJSON入出力を利用してください。

`main` ブランチへのpushで `.github/workflows/pages.yml` が静的サイトをビルドし、GitHub Pagesへ公開します。

## 保存と制作ツール

- **再編集**: 書き出しのJSONを「プロジェクトと版管理 → 読込」で開けます。旧形式のJSONにも対応します。
- **保存上限**: 20作品・各20版。上限で古い作品を自動削除しません。削除した作品はごみ箱から復元できます。
- **バックアップ**: プロジェクト画面から保存作品・全版・ごみ箱・ブランド色をまとめて保存／復元できます。復元は追加式で、容量不足や上限超過では既存データを変更しません。編集中の作品は先に新規保存してください。マイ見本一覧や表示設定はバックアップ対象外です。
- **制作ツール**: 文字用の余白（左・中央・右）、最大4案の一時比較、参考画像からの配色抽出、包装紙・布地・スライド・配信の使用イメージ。余白を有効にするとシームレスを解除します。模様の基本は1レイヤーのままです。
- **書き出し**: 用途別のおすすめ形式、構図プレビュー、1〜12ファイルのサイズ・配色別ZIP。WebMは4方向、1〜10秒、1〜4回移動、最大1920×1080相当（24fps目標）のループに対応します。動画は対応ブラウザーが必要で、フレーム数や長さは端末負荷により多少変動します。
- **参考画像**: PNG・JPEG・WebP（10MBまで）を端末内で処理し最大6色を抽出します。画像そのものは送信・保存しません。

## 生成画像の利用条件

生成した模様は商用利用可・クレジット表記不要です。第三者の参考画像・ロゴ・商標の権利は別扱いです。共有URLには作品設定が含まれ、URLを知る人は作品を閲覧しコピーを編集できます。非公開保存ではありません。
